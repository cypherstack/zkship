# zkship monorepo

- `zkship/`: Rust workspace implementing Zero-Knowledge Battleship (`zkb-core`, `zkb-session`, `zkb-wasm`, `zkb-relay`, `zkb-cli`, `zkb-bench`; see `zkship/README.md`)
- `Dockerfile`, `docker-compose.yml`, `docker-compose.tls.yml`, `deploy/`: Hardened container deployment for `zkb-relay` and web client integration guide
- `docs/`: Paper (`zk-battleship.tex` / `.pdf`) and BBCON 2026 extended abstract
- `zkship.com/`: Website (To Be Done)
